## Project

**RunningGames** — Godot 4.6 3D endless runner, prototype stage.

## Running & Building

This project has no custom build scripts — everything is managed by Godot.

```bash
# Open project in Godot editor
godot --path .

# Run the project headlessly (from CLI)
godot --path . --play

# Export (configure export presets in Godot editor first)
godot --path . --export-release "Windows Desktop" ./build/RunningGames.exe
```

## Project Configuration

- **Engine:** Godot 4.6, Forward Plus rendering
- **Physics:** Jolt Physics 3D
- **Rendering driver (Windows):** DirectX 12 (D3D12)
- **Language:** GDScript (C# support configured but inactive)

## Architecture

```
main.tscn (GameManager)
├── Player          → player.tscn + player.gd
├── Camera3D        → fixed offset follow cam
├── TrackSpawner
│   └── TrackChunk  → track_chunk.tscn + track_chunk.gd
│       └── Obstacle → obstacle_*.tscn + obstacle.gd
├── DirectionalLight3D + WorldEnvironment
└── HUD             → hud.tscn + hud.gd
```

### Scripts

| File | Node | Responsibility |
|---|---|---|
| `main.gd` | Node | Speed scaling, chunk pool (5 ahead), camera, score, game over |
| `player.gd` | CharacterBody3D | 3-lane movement, jump, slide, gravity |
| `track_chunk.gd` | StaticBody3D | Floor mesh, one obstacle spawn per chunk |
| `obstacle.gd` | Area3D | Hit detection → `call_group("game_manager", "on_obstacle_hit")` |
| `hud.gd` | CanvasLayer | Score label, game over panel, restart button |

### Player Mechanics

```gdscript
LANE_POSITIONS   = [-3.0, 0.0, 3.0]   # x positions
JUMP_FORCE       = 8.0                 # peak height = 1.6 units
GRAVITY          = 20.0
SLIDE_HEIGHT     = 0.9                 # capsule shrinks for 0.9s
NORMAL_HEIGHT    = 1.8
```

States: `RUNNING → JUMPING` (Space), `RUNNING → SLIDING` (↓), auto-reset on land/timer.

### Obstacle System

| Scene | Geometry | Required Action | Clearance math |
|---|---|---|---|
| `obstacle_high.tscn` | Floor hurdle, top=1.4 | **Jump** | Peak capsule bottom 1.6 > 1.4 ✓ |
| `obstacle_low.tscn` | Overhead beam, bottom=1.1 | **Slide** | Slide capsule top 0.9 < 1.1 ✓ |
| `obstacle_double.tscn` | Full-height wall, 2 lanes | **Switch lane** | Third lane always free ✓ |

Spawn weights: `obstacle_high` ~50%, `obstacle_low` ~25%, `obstacle_double` ~25%.
Spawn position: `z_local = randf_range(-9, -5)` relative to chunk center — min 15 units from near face.

### Speed Scaling

```gdscript
START_SPEED      = -10.0   # units/s
MAX_SPEED        = -22.0
SPEED_INCREMENT  = 0.05    # units/s² → ~240s to reach max
```

## Conventions

- Scripts live alongside their `.tscn` scene file
- Attach scripts via the Godot editor — do not manually create `.uid` files
- Use `res://` paths for all in-project resource references
- `.uid` files are auto-generated by Godot — do not commit them
- Game manager communication via group: `add_to_group("game_manager")` + `call_group(...)`
